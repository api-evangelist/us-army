# US Army (us-army)

The US Army is the largest branch of the United States military and is responsible for conducting ground combat operations. Its mission is to defend the nation and support humanitarian, peacekeeping, and training missions worldwide. The Army maintains a public API at api.army.mil providing access to news articles, events, and official content using OpenAPI 3 specification.

## APIs

### US Army Public API

The US Army Public API provides public access to Army news articles, events, and official announcements. Documented with OpenAPI 3 (OAS3) and a Swagger UI interface at api.army.mil. The API enables access to Army content including articles, news items, and public events.

- **Human URL:** [https://api.army.mil/](https://api.army.mil/)
- **Base URL:** `https://api.army.mil/api/v1`
